SMART EXPENSE CLASSIFIER - DEMO GUIDE
======================================

HOW TO RUN THE DEMO:
--------------------

Method 1 (Easiest):
  Double-click: RUN_DEMO.bat

Method 2 (Command Line):
  streamlit run app/demo_app.py

The app opens at: http://localhost:8501


WHAT TO DO IN THE DEMO:
-----------------------

1. SINGLE PREDICTION:
   - Type a transaction (e.g., "Starbucks coffee")
   - Click "Predict Category"
   - See the result with confidence score

2. QUICK EXAMPLES:
   - Click the example buttons (Starbucks, Uber, Amazon, Netflix)
   - Instant predictions

3. VIEW VISUALIZATIONS:
   - Confidence gauge (right side)
   - Top 3 predictions with progress bars
   - Full category probability chart

4. BATCH PREDICTION:
   - Scroll down to "Batch Prediction"
   - Upload a CSV file
   - File must have 'transaction_description' column
   - Click "Predict All"
   - Download results

TROUBLESHOOTING:
---------------

Problem: App doesn't start
Solution: 
  python -m pip install streamlit
  python -m streamlit run app/demo_app.py

Problem: Model not found
Solution:
  Check models/final_expense_classifier.joblib exists
  If missing, retrain model

Problem: Browser doesn't open
Solution:
  Open manually: http://localhost:8501

Problem: Port already in use
Solution:
  streamlit run app/demo_app.py --server.port 8502
